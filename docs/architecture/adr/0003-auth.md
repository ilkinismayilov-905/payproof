# ADR-0003: Autentifikasiya və səlahiyyət
**Status:** qəbul edilib · 2026-11-08

**Qərar:**
- Backend yalnız JWT yoxlayır (`sub`, `company_id` deyil — üzvlük DB-dən). Rol və tenant `memberships` cədvəlindən.
- Dev/demo: `POST /v1/auth/dev-login` demo istifadəçi üçün lokal açarla JWT verir (yalnız `ENV=dev`). UI-də "Demo hesabını seç".
- Prod (sonra): idarə olunan provayder (Clerk və ya Auth0) — backend JWKS ilə yoxlayır. Kod dəyişikliyi yalnız `auth/verifier.py`-da.
- Səlahiyyət matrisi bir yerdədir (`domain/permissions.py`); frontend onu `GET /v1/me`-dən alır.
