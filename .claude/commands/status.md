---
description: Bütün track-lərin vəziyyəti və bloklanmalar
---

1. `docs/progress/*.md` fayllarını oxu (remote varsa əvvəl `git fetch`; `origin/main`-dəki versiyanı da müqayisə et).
2. Hər track üçün: ✅ / 🟡 / ⬜ / 🚧 sayı, hazırkı step, növbəti mümkün step.
3. Paralel track-lərin bir-birini blokladığı yerləri göstər (məs. W-18 → B-24 gözləyir).
4. Açıq branch-lar: `git branch --list 'feat/*'` və `git worktree list`.
5. `docs/progress/CONTRACT-CHANGELOG.md`-də son dəyişiklik və frontend-in onu tətbiq edib-etmədiyi.
Qısa cədvəl şəklində cavab ver; heç nəyi dəyişmə.
